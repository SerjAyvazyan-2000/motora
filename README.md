# MOTORA — шаблон лендинга автосервиса

Одностраничник на чистых HTML, CSS и JS, без сборки и зависимостей.

## Структура
```
index.html
assets/
  css/style.css   — стили (цвета и шрифты в :root)
  js/config.js    — ВСЯ информация клиента (редактировать только его)
  js/main.js      — анимации и логика
  images/         — схема автомобиля и иконка сайта
```

## Настройка под клиента
1. Откройте `assets/js/config.js`. Там название, телефон, адрес, расписание, услуги и цены по узлам, калькулятор, этапы работы, гарантии, отзывы, FAQ и цвета.
2. Точки на схеме автомобиля: `systems[].x / y`, координаты в процентах.
3. Статус «Открыто / Закрыто» сайт считает сам по расписанию `contacts.schedule`.
4. Карта: в `contacts.mapEmbed` вставьте src виджета Яндекс Карт.
5. Заявки задаются в `booking.mode`: `whatsapp`, `telegram`, `endpoint` (POST JSON на ваш URL) или `demo`.
6. Цвет акцента меняется в `theme.accent`.

## Блоки и эффекты
- Прелоадер: открываются гаражные ворота и идёт отсчёт «system check»
- Hero: машина едет при прокрутке, колёса крутятся пропорционально пройденному пути, спидометр показывает скорость, передачу и обороты, есть параллакс сетки и фонового текста, контуры машины прорисовываются при загрузке
- Бегущая строка марок ускоряется и наклоняется в зависимости от скорости скролла
- Счётчики-одометры с вращающимися цифрами
- Интерактивная схема автомобиля: нажимаете на узел и видите цены, есть сканирующая линия
- Горизонтальный скролл этапов работы (на телефоне — свайп)
- Калькулятор со сметой-чеком: тип авто × услуги, сумма пересчитывается с анимацией и подставляется в заявку
- Карточки гарантий складываются в стопку при скролле
- Отзывы колодой карт: их можно смахивать мышкой или пальцем
- Форма записи с полем госномера в виде номерного знака (латиница сама меняется на кириллицу), маской телефона и окном «заказ-наряд» после отправки
- Cookie-баннер в виде лампы на приборной панели, с настройками
- Кастомный курсор, магнитные кнопки, статус «Открыто сейчас»
- Адаптив для экранов от 320px; учитывается настройка `prefers-reduced-motion`
